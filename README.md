📈 Análise e Previsão de Séries Temporais: IPCA Acumulado em 12 Meses (IBGE)

Disciplina: C11 — Ciência de Dados / Análise de Séries Temporais

Instituição: Instituto Nacional de Telecomunicações (Inatel)

Professor: Dr. Renzo Mesquita Paranaíba

📋 Sobre o Projeto

Este projeto realiza a análise exploratória, decomposição estrutural e modelagem preditiva da série temporal do Índice Nacional de Preços ao Consumidor Amplo (IPCA) acumulado nos últimos 12 meses, utilizando dados oficiais do IBGE.

O objetivo principal é compreender o comportamento histórico da inflação brasileira (tendência, sazonalidade e ciclos econômicos), avaliar o desempenho de diferentes algoritmos clássicos de previsão em um conjunto de validação e projetar o comportamento do indicador para os próximos 24 meses.
